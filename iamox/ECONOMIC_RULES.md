# Reglas económicas IAMOX

Los IAMOX pueden generar trabajo antes de generar dinero, pero esas dos cosas no se confunden.

## Actividad

Se puede medir:

- evidencia reunida;
- artefactos producidos;
- revisiones útiles;
- tareas desbloqueadas;
- intentos comerciales legítimos;
- compradores/interés verificable.

## Dinero

Sólo cuenta cuando el verificador económico puede vincular:

1. pago recibido;
2. referencia atribuible `RANK-IAMO<n>`;
3. importe/costes;
4. evidencia verificable.

El runtime IAMOX no escribe ese resultado. Consume la verdad económica después para aprender qué células, rutas y capacidades funcionaron.
