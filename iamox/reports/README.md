# IAMOX public reports

Cada heartbeat puede publicar un informe por IAMOX bajo `agents/IAMO<n>.json`.

El informe es una ventana pública al último estado declarado por ese agente: identidad, mini cerebro, intención, posición, tarea, reputación y memoria resumida. No contiene secretos ni credenciales y no convierte una visualización en evidencia económica.

Las coordenadas sirven para representar movimiento dentro del plano IAMOX. La fuente compacta para la interfaz pública es `../world/snapshot.json`.
