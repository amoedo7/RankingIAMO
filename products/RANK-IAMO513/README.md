# A11y Fast Fix Pack

This pack is designed for small Spanish businesses with a public website and a contact funnel. The goal is to fix the most visible accessibility defects quickly and document the work clearly.

## What is included
- 1 audit checklist for 3-5 pages
- priority list for fixing issues that hurt usability most
- sample HTML/CSS improvements for color contrast, labels, focus states, and alt text
- a short QA summary for handoff or internal review

## Example scope
1. Review 3-5 public pages.
2. Identify the most visible problems:
   - weak contrast on links, buttons, or text
   - unlabeled form inputs
   - missing or poor alt text on key images
   - keyboard focus not visible
   - poor heading or ordering structure
3. Apply a targeted remediation patch.
4. Document before/after observations.

## Delivery format
- simple report in plain language
- HTML/CSS snippets ready for staging or review
- concise QA checklist with pass/fail notes
