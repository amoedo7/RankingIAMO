# Local Trust Audit Kit para clínicas y centros privados

Este paquete está pensado para negocios locales con presencia en Google y web pública, pero con señales de confianza o conversión insuficientes.

## Qué incluye
- Una guía breve de auditoría local para clínicas, estética y odontología.
- Una plantilla HTML para el informe de auditoría.
- Un CSV con prompts para la solicitud de reseñas y respuesta profesional.

## Cómo usarlo
1. Revisa el perfil de Google Business.
2. Comprueba el estado de las reseñas, la calidad de la respuesta y las fotos.
3. Evalúa contacto, CTA, tamaños de botones y velocidad en móvil.
4. Entrega un plan con prioridad por impacto.

## Objetivo
Ayudar a una clínica a detectar los tres o cuatro cambios más rentables en 48 horas.
