# Shopify Feed Health Pack

## Qué incluye
- Auditoría visual y técnica de 3-10 SKU críticos
- Corrección de títulos, variantes, URLs, imágenes y referencias
- CSV exportado listo para revisión y reimportación
- Checklist QA con 10 puntos

## Cómo se entrega
1. Reúnes las URL de los productos a revisar
2. Se auditan los SKU con mayor impacto visible
3. Se corrigen títulos, variantes, URLs, GTIN/MPN e imágenes
4. Se entrega PDF + CSV + checklist QA
