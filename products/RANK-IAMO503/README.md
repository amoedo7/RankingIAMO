# Review Response Studio

MVP para clínicas que necesitan responder reseñas de Google con criterio y rapidez.

## Qué incluye
- clasificación de reseñas por impacto y riesgo
- respuesta sugerida según tipo de comentario
- priorización semanal para el equipo
- formato listo para revisión humana antes de publicar

## Cómo usarlo
1. Abre `review-response-studio.html` en un navegador.
2. Copia la reseña y el tipo de tratamiento asociado.
3. El asistente sugiere una respuesta en tono médico-profesional.
4. Revisa la propuesta y publícala con la aprobación del equipo.
