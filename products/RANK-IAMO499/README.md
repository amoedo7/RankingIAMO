# GitHub Actions Setup Kit

## Objetivo
Automatizar un flujo repetitivo de CI para pequeños equipos de software que usan GitHub y repiten tareas manuales de lint, test, build y validación.

## Qué incluye
- Revisión breve del repo para detectar el trabajo repetido más claro
- Workflow reutilizable de GitHub Actions para CI de Node.js
- Checklist de variables/secrets y pasos obligatorios para rollout
- Documento de soporte con limité y revisión de 2 semanas

## Uso básico
1. Copiar `.github/workflows/ci.yml` al repositorio.
2. Revisar `docs/ci-secrets-checklist.md`.
3. Añadir las variables o secrets requeridos en GitHub.
4. Ejecutar el workflow en push o pull request.
