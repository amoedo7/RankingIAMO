# GBP Review & Rank Pulse Pilot

Este MVP ayuda a un negocio local a revisar reseñas nuevas, detectar riesgo de reputación y seguir movimientos de visibilidad. Está pensado como un piloto de 30 días, con una salida clara y lista para presentar a un cliente.

## Qué incluye
- un CSV de ejemplo con reseñas y posiciones locales
- un script Python para resumir señales de riesgo
- un dashboard HTML para inspeccionar la evolución del perfil

## Uso
1. Añade tus registros en `sample_reviews.csv`
2. Ejecuta: `python gbp_review_alert_minimal.py sample_reviews.csv`
3. Abre `dashboard.html` en el navegador

## Alcance comercial
- nuevas reseñas por día
- valoración media
- comentarios negativos y palabras clave de riesgo
- cambios de ranking comparados con la competencia
- recomendaciones de respuesta
