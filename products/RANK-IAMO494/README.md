# Sprint Web Performance 494

Este paquete está diseñado para ofrecer un sprint concreto de mejora de rendimiento web a negocios con presencia online. El objetivo es detectar ralentizaciones visibles en móvil y desktop, priorizar cambios con impacto directo y dejar un plan ejecutable.

## Qué incluye
- Auditoría técnica de 2-5 páginas clave
- Diagnóstico de Core Web Vitals y velocidad de carga
- Revisión de imágenes, CSS, JS y orden de renderizado
- Prioridades por volumen de impacto y facilidad de corrección
- Checklist de mantenimiento para repetir en futuras revisiones

## Cómo usarlo
1. Revisa el sitio del cliente.
2. Ejecuta una auditoría con PageSpeed Insights o Lighthouse.
3. Extrae problemas visibles y documenta los puntos más importantes.
4. Entrega el informe con prioridades y una hoja de seguimiento.
