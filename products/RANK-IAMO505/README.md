# Shopify Feed QA Sprint

Este paquete entrega un MVP práctico para auditorías de catálogo de productos e-commerce.

## Objetivo
Ayudar a tiendas con 30-300 SKU a detectar y corregir inconsistencias que bloquean o degradan Google Shopping y Meta Catalog.

## Qué incluye
- Auditoría de product feed en CSV
- Detección de títulos duplicados, variantes inconsistentes, GTIN/MPN vacíos y URLs rotas
- Lista de verificación de calidad final
- Guía de entrega para el cliente

## Uso rápido
1. Exporta el CSV de productos de Shopify.
2. Ejecuta el script `scripts/catalog_feed_audit.py`.
3. Revisa los hallazgos y corrige títulos, variantes y atributos.
4. Carga el CSV corregido y comparte la checklist final.
