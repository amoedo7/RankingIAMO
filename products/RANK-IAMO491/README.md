# Kit de auditoría técnica local

## Objetivo
Este kit está pensado para negocios locales que tienen web pública, perfil local activo y oportunidades claras de mejorar velocidad, confianza y conversión.

## Qué incluye
- Guía de auditoría técnica web
- Plantilla de informe en HTML
- Checklist de mejoras priorizadas
- Recomendaciones de implementación

## Uso
1. Revisa la web del negocio.
2. Comprueba velocidad, CTA, formularios y contacto.
3. Aplica el checklist y prioriza cambios por impacto.
4. Entrega el informe final con un plan de acción.
