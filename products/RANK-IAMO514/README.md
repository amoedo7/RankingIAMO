# Factura Clara ES

Generador local de presupuestos y facturas para freelancers y microestudios españoles.

## Qué incluye

- `generator.html`: herramienta funcional que corre en el navegador y no necesita servidor.
- `concepts.csv`: plantilla opcional para conservar un catálogo de servicios y precios.
- `SETUP.md`: configuración rápida y recomendaciones de revisión.

## Uso rápido

1. Abrí `generator.html` en Chrome, Firefox, Edge o Safari.
2. Completá los datos del emisor y del cliente.
3. Elegí `Presupuesto` o `Factura`.
4. Agregá las líneas de trabajo, el IVA, el descuento y las condiciones de pago.
5. Pulsá `Actualizar documento` y luego `Imprimir / guardar PDF`.
6. Guardá el PDF en tu sistema habitual y verificá los datos antes de enviarlo.

La herramienta funciona de manera local: los datos introducidos no se envían a ningún servidor.

## Alcance

Este MVP está pensado para documentos comerciales habituales de profesionales y pequeños estudios. No implementa series fiscales, rectificativas, intracomunitarias, inversión del sujeto pasivo, SII, VERI*FACTU ni otras casuísticas especiales. Consultá a tu asesoría para determinar los requisitos que correspondan a tu actividad.
