# RANK-IAMO497

## Producto
Kit de lanzamiento para clínicas locales con tráfico activo y baja conversión.

### Qué incluye
- Landing de una sola pantalla para un servicio concreto
- Copy orientada a conversión y CTA visible
- Bloque de confianza y FAQ breve
- Recomendaciones de perfil local y reseñas
- Checklist de 30 días para cerrar más consultas

### Uso recomendado
1. Seleccionar un servicio de alto valor: implantes, ortodoncia, estética, cirugía menor, consulta inicial.
2. Sustituir textos y datos del caso real de la clínica.
3. Publicar la landing en un subdominio o hosting estático.
4. Añadir CTA a WhatsApp o llamada desde la primera sección.
5. Pedir reseñas nuevas y responder de forma rápida.
