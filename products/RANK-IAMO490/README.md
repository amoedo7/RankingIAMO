# Shopify Feed Cleanup Sprint

## Objetivo
Este paquete ayuda a un comercio DTC a detectar y corregir los problemas más comunes en su catálogo Shopify: títulos duplicados, variantes inconsistentes, URLs, imágenes, campos GTIN/MPN, códigos SKU y errores de exportación CSV.

## Qué incluye
- Auditoría rápida de catálogo
- Checklist de validación de feeds
- Script para detectar errores típicos
- Plantilla de acción para mantener el feed limpio

## Entrega
- 1 CSV/archivo normalizado para revisión
- 1 checklist de validación
- 1 resumen de problemas detectados

## Uso
1. Exporta el catálogo desde Shopify.
2. Ejecuta `python catalog_feed_audit.py catalog.csv`.
3. Revisa los problemas de títulos, variantes, imágenes y campos vacíos.
4. Aplica limpieza y valida con la checklist.
