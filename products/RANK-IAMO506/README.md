# Website Fix Pack

Este paquete está diseñado para detectar un bloqueo visible de conversión en una web local y entregar una corrección concreta, útil y fácil de vender.

## Objetivo
Corregir 1 problema objetivo en la conversión del negocio: teléfono oculto, CTA roto, WhatsApp sin funcionar, formulario sin enviar o contacto desactualizado.

## Qué incluye
- Auditoría rápida del sitio
- Identificación del problema principal
- Corrección del problema en la web o una copia de trabajo
- Capturas antes/después
- Resumen de impacto para el cliente
