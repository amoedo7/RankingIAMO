# GBP Review Recovery Sprint Kit

This MVP is a practical asset for service businesses that want a clearer local review signal and a simpler, faster response process.

## Included
- Quick profile audit checklist
- Review gap analysis worksheet
- Response templates for positive, neutral, and negative feedback
- Review request workflow for staff or reception
- 14-day action plan

## Delivery
The sprint is fixed-scope and designed to be implemented by a small local team without a larger platform build.
