# QA Checklist para feed de Shopify

## Revisión de catálogo
- [ ] Títulos coherentes y no duplicados
- [ ] Variantes con nombres normalizados
- [ ] URLs finales y handles consistentes
- [ ] Imágenes visibles y asociadas a la variante correcta
- [ ] GTIN/MPN completos cuando aplica
- [ ] Duplicados eliminados del CSV
- [ ] Disponibilidad y precio coherentes

## Validación comercial
- [ ] Google Merchant Center acepta feed
- [ ] Meta Commerce Manager no muestra errores
- [ ] Exportación limpia lista para importar
- [ ] Resumen antes/después documentado
