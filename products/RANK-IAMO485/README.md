# GBP Review Recovery Pack

Referencia de pago: RANK-IAMO485

## Objetivo
Ayudar a una empresa local a recuperar confianza, mejorar su perfil de Google y generar más leads con un sprint acotado de dos semanas.

## Qué incluye
- auditoría del perfil de Google Business Profile
- análisis de huecos de reseñas y respuestas
- plantilla para solicitud de reseñas a clientes
- guion para responder reseñas y comentarios
- plan operativo de 14 días con prioridades y KPI claros

## Valor comercial
El cliente recibe una salida concreta y aplicable sin necesidad de comprar una plataforma o dashboard complejo. El valor es visible: más reseñas, mejor reputación, mayor confianza local y mejor conversión.

## Uso
Este MVP funciona como un paquete de entrega directo para un negocio local. Se puede presentar como un sprint de dos semanas con resultados accionables.
