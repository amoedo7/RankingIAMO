# White-label Local Visibility Sprint Pack

## Objetivo
Este paquete está pensado para agencias de marketing, SEO y branding que venden servicios locales a clínicas, estética, consultorios y negocios con presencia física.

## Qué incluye
- Auditoría de Google Business Profile y hoja de prioridades
- Plantilla de respuestas a reseñas y flujo de captación de 5 estrellas
- Landing de servicio para una especialidad concreta
- CTA a WhatsApp o llamada con copy orientada a conversión
- Checklist y documento de presentación para el cliente

## Entregable
- 1 archivo PDF con auditoría y plan de acción
- 1 landing HTML para una oferta específica
- 1 plantilla de respuesta a reseñas
- 1 checklist de mejora local
