# Conversion Rescue Pack

Un pack de diagnóstico para negocios locales con páginas públicas y bloqueos de conversión visibles: teléfono oculto, CTA rota, WhatsApp sin enlace, formulario poco visible o horario desactualizado.

## Qué incluye
- `index.html`: mini herramienta local para generar un informe de bloqueo de conversión.
- `conversion-checklist.csv`: checklist de errores y acciones de reparación.
- `audit-template.md`: plantilla para entregar el diagnóstico a un cliente.

## Cómo usarlo
1. Abre `index.html` en un navegador.
2. Completa nombre del negocio, URL de la web, tipo de problema y CTA principal.
3. Genera el resumen ejecutivo.
4. Usa la plantilla `audit-template.md` para entregar antes/después y recomendaciones.
