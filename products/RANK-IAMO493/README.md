# Kit de auditoría y corrección rápida de accesibilidad web

## Objetivo
Este kit está pensado para pequeñas empresas con web pública en España que tienen problemas visibles de accesibilidad: contraste, foco, textos alternativos, etiquetas de formulario, jerarquía de headings y navegación por teclado.

## Qué incluye
- Auditoría de 5-10 páginas
- Lista priorizada de 10 fallos accesibles
- Correcciones HTML/CSS de los puntos más obvios
- Checklist final de validación
- Recomendaciones de mantenimiento

## Cómo usarlo
1. Revisa la web del negocio.
2. Documenta un conjunto de páginas clave: inicio, servicios, contacto y formularios.
3. Comprueba contraste, foco, enlaces, imágenes y formularios.
4. Prioriza los fallos por impacto en usuarios y búsqueda.
5. Aplica los cambios básicos y entrega la lista final.
