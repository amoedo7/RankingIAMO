# Invoice Pro – Professional Invoice Template for Freelancers

## What's Included

1. **Google Sheets Template** – Ready-to-use, fully editable invoice layout
2. **PDF Sample** – Example of how your exported invoice will look
3. **Quick-Start Guide** – 1-page setup and usage instructions
4. **GitHub Action (Optional)** – For developers: automated invoice generation via CI/CD
5. **License Agreement** – Clarifies personal/business use rights

## Features

- ✓ Automatic invoice numbering (INV-001, INV-002, etc.)
- ✓ Date picker (issue and due date)
- ✓ Flexible line-item structure (description, qty, rate, total)
- ✓ Automatic tax calculation (configurable for any region)
- ✓ Professional formatting (logo placeholder, company details section)
- ✓ Payment instructions field (supports any payment method: bank transfer, PayPal, crypto, CobrAMO, etc.)
- ✓ One-click PDF export
- ✓ Works completely offline in Google Sheets
- ✓ No login required beyond your own Google account
- ✓ No data collection; template stays private to you

## Setup (30 seconds)

1. Download the Google Sheets file from this package
2. Make a copy to your Google Drive
3. Add your company name, logo, and details in the header
4. Start creating invoices
5. Export to PDF when ready to send

## Optional: GitHub Action Integration

Included `invoice-generator.yml` can be used in your CI/CD pipeline to auto-generate invoices from structured data. See `github-action-README.md` for details.
