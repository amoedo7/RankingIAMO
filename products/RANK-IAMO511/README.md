# Mini-audit de conversión para clínicas locales

Este kit está pensado para clínicas con Google Business Profile activo y una web pública con un bloqueo visible de contacto.

## Objetivo
Identificar el bloque principal de conversión en una página clave y proponer una corrección concreta y verificable.

## Qué incluir
- Revisión de la home o servicio clave
- Detección de teléfono oculto, WhatsApp roto, CTA poco visible o formulario sin foco
- Corrección en sitio o staging
- Resumen antes/después y recomendaciones priorizadas

## Uso
1. Seleccionar una página clave de la clínica.
2. Revisar si el número, WhatsApp o CTA están ocultos o poco claros.
3. Corregir el elemento principal.
4. Documentar el antes/después.
