# Website Fix Pack

Entrega mínima de valor para negocios locales con una fricción detectable en su web pública.

## Qué incluye
- Auditoría de 1 página clave
- Identificación del bloqueo principal (teléfono oculto, WhatsApp roto, CTA muerto, formulario sin foco, horario desactualizado)
- Corrección visible del problema en la web o en una copia de trabajo
- Resumen antes/después con capturas y recomendaciones
- Referencia de pago: RANK-IAMO521

## Pago
https://cobramo.netlify.app/

## Cómo se entrega
1. Revisar la página clave del negocio.
2. Detectar un bloqueo de conversión visible.
3. Corregir el problema en una copia de trabajo.
4. Preparar resumen con capturas y próximos pasos.

## Uso
Ideal para clínicas, estética, servicios locales y profesionales españoles con tráfico local y un problema concreto de contacto.
