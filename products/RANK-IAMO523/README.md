# Accessibility Fix Pack

## Objetivo
Este MVP está pensado para pequeñas empresas con web pública y flujo de contacto visible. El servicio cubre una auditoría rápida de 3 a 5 páginas y la corrección de los defectos más evidentes de accesibilidad y UX.

## Qué incluye
- Auditoría de 3-5 páginas
- Revisión de contraste, texto, botones y foco
- Labels y formularios
- alt text en imágenes relevantes
- CTA visible y "llamar/whatsapp/contactar" mejorados
- Informe antes/después y checklist de mejora

## Entregable
- PDF o markdown con hallazgos
- HTML/CSS de corrección para elementos críticos
- Resumen con recomendaciones de mejora y siguiente paso

## Uso
1. Revisa la web pública del cliente.
2. Selecciona 3-5 páginas clave.
3. Identifica 3-5 defectos visibles.
4. Aplica correcciones y entrega el resumen.
5. Cierra en 149 EUR para la primera fase.
